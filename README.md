# kylescudder's Homebrew Tap

One tap for all my projects.

```sh
brew tap kylescudder/tap
```

| Cask | Description |
| --- | --- |
| `balm` | Native, keyboard-driven SwiftUI client for Jira Cloud |
| `herdr` | Terminal workspace manager for AI coding agents (personal fork with worktree grouping) |
| `lgtm` | Native client for reviewing and approving Azure DevOps pull requests |
| `spark-plug` | Menubar launcher for coding-agent sessions in your worktrees |

```sh
brew install --cask balm
brew install --cask herdr
brew install --cask lgtm
brew install --cask spark-plug
```
